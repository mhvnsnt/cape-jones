# HERO FILES CATALOG — free / public-domain hero assets
Researched 2026-10-14/15. Bottom line up front: there is NO single
"free public CN-gigaleak-level public-domain hero archive." What exists:
real, verified, free sources below. Superman is NOT public domain
(see §4).

## 1. Quaternius — Universal Base Characters (CC0) ⭐ best 3D hero pick
- Pack page: https://quaternius.com/packs/universalbasecharacters.html
- Free download: https://quaternius.itch.io/universal-base-characters
  (name-your-price, $0 works)
- License: CC0 1.0 Universal — personal, educational, commercial, no attribution.
- Contents: 6 game-ready base models — Superhero / Regular / Teen × Male/Female;
  20 hairstyles; customizable eye/skin color; humanoid rig (retargetable, UE-style
  65-joint skeleton); ~13k tris; FBX + glTF.
- Size: "Universal Base Characters[Standard].zip", ~122–129 MB.
- SHA-256 (Standard, 2026-08-30): fdbf1804c90dfc1ea03e992bff7da2dfd1a79318e13270a660180f9308455f40
- Companion: Universal Animation Library (CC0) — 43 clips, ~15–17 MB:
  https://quaternius.itch.io/universal-animation-library
  (same skeleton, clips bind by bone name — verified by third-party builds).

## 2. Blender open movies — production files (CC-BY)
- Hub: https://studio.blender.org/films/
- License: CC-BY (attribution required) on films + production files.
- Older films (Big Buck Bunny, Sintel, Tears of Steel, Elephants Dream):
  full production files (.blend scenes, rigs, textures) with direct free downloads.
- Newer films (Spring, Sprite Fright, Charge, Wing It!, …): still CC-BY licensed,
  BUT project-file downloads currently require a Blender Studio subscription
  (~€11.50/month). Free as in speech, not as in beer, for the new ones.

## 3. Digital Comic Museum — public-domain golden-age hero comics
- Site: https://digitalcomicmuseum.com (free registration, no per-download charge)
- Thousands of researched-confirmed PD Golden Age issues: Smash Comics, Boy Comics,
  Whiz Comics (Captain Marvel), Wow Comics (Mary Marvel), Startling Comics
  (Pyroman, Fighting Yank), etc. Typical issue: 50–150 MB CBZ/PDF.
- Also: ComicBookPlus (comicbookplus.com) — same category, PD golden-age archive.
- NOTE: these are 2D comic scans — art/reference/likeness source, not 3D models.

## 4. Superman — NOT public domain ⚠️
- Superman (Action Comics #1, 1938) enters US public domain on **January 1, 2034**
  (95-year term). Source: https://publicdomaincountdown.com/public-domain/superman
- Even then: ONLY the 1938 version. Flight, Daily Planet, Jimmy Olsen, Lex Luthor,
  kryptonite, the S-shield logo and the name as a trademark all remain protected.
- There are NO legit free/public-domain Superman model/asset packs today.

## 5. Cartoon model sheets on archive.org (free download — characters NOT PD)
- Dexter's Lab (Dee Dee) model sheets: https://archive.org/details/dexters-lab-dee-dee
- Powerpuff Girls drawing guide: https://archive.org/details/powerpuffgirlsdrawingguide
- Cow & Chicken (Red Guy) model sheets: https://archive.org/details/cowchickenredguy
- These are production art freely downloadable, but the CHARACTERS remain
  copyrighted — study/reference use, not a public-domain grant.

## Recommendation
For a hero game/show needing actual 3D heroes today: start with Quaternius
Universal Base Characters (CC0, rigged, animated via the Universal Animation
Library). For 2D reference and PD hero likenesses: Digital Comic Museum.
There is no PD Superman until 2034.
