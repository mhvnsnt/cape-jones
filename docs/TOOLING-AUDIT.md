## Corrections this audit establishes (prior claims were wrong)

1. **The repo's vendored COA is NOT the Aodaruma release — contradicted.** `production/tools/coa_tools2/` (landed PR #430) is the hcqmaker fork v2.3.1, `bl_info` Blender (5,1,2), 17 MB. It **FAILS to enable on this VM's Blender 5.0.1**: `SyntaxError: f-string: expecting '}' (export_godot_tscn.py, line 1526)` — PEP 701 f-string syntax needing Python 3.12+; Blender 5.0.1 bundles Python 3.11.13. Its manifest still says 2.3.0/Aodaruma (not bumped). Next route: use the Aodaruma v2.3.0 vendored here, or patch that one PEP-701 line, or move the VM to Blender 5.1.2+. Do not claim the PR #430 COA works on this VM — it does not.
2. **Wiggle 2 was nowhere in the repo — verified.** Full main-tree scan (53,482 paths): zero paths containing "wiggle". PR #430 landed COA only. It is wired in by this PR.
3. **"Gumball S2 `.fla` rigs found on disk (9 files)" — contradicted.** Workspace-wide `find -iname "*.fla"`: **0 files**. `~/workspace/agent-ops/` does not exist on this VM. The repo `mhvnsnt/cn-gigaleak-gumball` (private, verified live) has **no `.fla` in its git tree** (root is PDFs + docs; `search_code … fla` = 0 results). Per that repo's own HANDOFF, the 9 rigs live in a draft release, `untagged-1676e192ae8c72e95791` ("Gumball S2 Rigs, gigaleak pull v1") — **unverified**: release asset list was not readable from here (no `gh` auth, connector release tools need approval). Next route: verify that release's asset list (9 `.fla` files?) on a git-authenticated machine or via browser, download one rig, open it, extract layer list / symbol hierarchy / joint pivots — study-only (method/timing/structure only; never Gumball art, characters, or logos in show files). Until then, no `.fla` rig structure can be described from a real file — do not invent one. The method to copy in the meantime is the Flash-puppet method already in `docs/TV-SHOW-METHOD-STUDY.md`: draw once → cut apart into layered symbols → rig like a puppet → pose/tween the rig; face parts as swappable symbol libraries; cape as its own follow-through piece.

Do not treat them as in-hand until then.
