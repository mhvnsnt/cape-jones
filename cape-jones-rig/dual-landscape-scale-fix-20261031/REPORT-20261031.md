## 2. Whole-figure fit — plainly, no silent shrink
A whole figure at master scene scale does NOT fit a 1920x1080
frame without a window:
- 2.5x scene height 1165 > 1080 by 85px.
- 3.0x scene height 1398 > 1080 by 318px.
- Master centre crop (y420-1500, proof file
  master-centre-crop-CUT-20261031.png): cuts head 35px
  (385 -> 420) and feet 50px (1550 -> 1500).
The fix is therefore a pull-back WINDOW in the master scene,
not a fresh 1080 composition and not a figure-only shrink:
the window contains the whole figure + ~40px margin, is
16:9, and is resized to 1920x1080. Figure and room shrink
TOGETHER by the window factor only, so the figure-to-furniture
ratio is preserved (2.5x) or increased exactly 1.2x (3.0x).

## 4. Mandatory scale gate — the fix for the regression
File: check_scale_gate.py. Run it BEFORE any landscape delivery.
It FAILS LOUDLY (exit 2, "DO NOT SHIP") if any of:
  - final figure height < 1000px in a 1920x1080 landscape, OR
  - figure-to-chair ratio < 1.42, OR
  - figure not whole (head < 0 or feet > 1080).
It prints, on every run, that % -of-frame height alone is NEVER
a scale pass. Test results, actually run in this folder:
  - reverted landscape (655px, 1.193): FAIL, exit 2, both criteria.
  - old dual proof (709px, 1.30): FAIL, exit 2.
  - new 2.5x (1010px, 1.423, whole): PASS, exit 0.
  - new 3.0x (1022px, 1.710, whole): PASS, exit 0.
Had this gate been run before the first landscape delivery, the
655px version could not have shipped. The old master gate
(0.607 ratio + feet-on-rug) is NOT a landscape gate and must
not be quoted as one again.
