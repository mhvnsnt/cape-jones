# Scale-anchor methods — industry-standard, wired 100% in this folder

The regression was a method failure, not just a number failure:
the first landscape used % -of-frame as its scale anchor. These
methods replace that anchor. RUN = implemented in
build_landscape_scale_fix.py and/or check_scale_gate.py in this
folder, with a file to prove it. MAPPED = described as a method,
NOT claimed run, with the reason it is not a run here.

## RUN (5)
1. Furniture / reference-object anchor — production layout
   practice: a known object in the room anchors character scale.
   Here: the armchair, chair-back top scene y~700, chair feet
   y~1518, chair height 818px in scene. Every version reports
   figure-to-chair ratio (master 1.424, reverted 1.193,
   2.5x 1.423, 3.0x 1.710). If the ratio drops, the figure
   regressed relative to the room, whatever the frame is.
2. Floor-plane / horizon anchor — animation layout practice:
   feet sit on a single floor line in scene coordinates.
   Here: scene feet y=1550 for BOTH new versions (3.0x growth
   goes up from the floor, never down through it). Feet y is
   in every measurements entry, not assumed.
3. Model-sheet / character-height anchor — character model
   sheets fix one canonical standing height. Here: rig 950px
   at 2.5x, master scene figure 1165px, 3.0x scene figure
   1398px (= 1165 x 1.2). The builder places the figure from
   that scene height, never from "60.7% of this frame".
4. Pull-back camera window (overscan / camera pull-back) —
   live-action and layout practice: move the camera back to
   fit a subject, do not shrink the subject relative to its
   world. Here: a 16:9 window in the 2860x1920 scene,
   containing the whole figure + ~40px margin, resized to
   1920x1080. Window factors: 2.5x 0.8676, 3.0x 0.7306.
   Figure and room shrink together by that factor ONLY.
5. Mandatory fail-loud gate — production QC practice: a
   delivery check that blocks, not a note. Here:
   check_scale_gate.py, exit 2 on height < 1000px OR ratio
   < 1.42 OR not whole, exit 0 only on all three. Actually
   run: reverted FAIL, old FAIL, 2.5x PASS, 3.0x PASS.

## MAPPED, NOT RUN (2)
6. Broadcast safe-area / open-gate framing — TV/broadcast
   practice: protect a subject area and check it against
   safe-action/title areas. Mapping only here: the previous
   dual-orientation work already used safe overlays; this
   folder does not re-run a broadcast safe-area tool, and
   no such run is claimed. The pull-back window's 29-35px
   head/feet margins are the in-folder equivalent, stated
   as margins, not as a broadcast certification.
7. Production layout scale charts — storyboard/layout
   practice: a scale chart sheet showing the character
   against furniture at several scales. Mapping only here:
   the before/after contact (reverted | 2.5x | 3.0x) IS the
   in-folder scale chart, but no external studio chart
   tool was run. The chart is a viewed proof file, not a
   vendor run.

## Explicitly NOT a method here
- % -of-frame height (655/1080 = 0.607) is NOT a scale anchor.
  It caused the regression and is banned as a pass criterion
  by check_scale_gate.py, which prints that warning every run.
- Resizing figure and room independently to fit a frame is
  NOT pull-back. Pull-back resizes ONE window containing both.
