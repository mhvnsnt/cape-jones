## 1. Storyboard + animatic standards — PARTIALLY WIRED
- What: panel language (one drawing = one shot beat), camera-move arrows, timing written
  under each panel, sound/dialogue synced to the animatic timeline before animation starts.
  Source: standard TV storyboard practice (Disney/TV animation pipeline; Preston Blair /
  studio storyboard conventions) and the existing PIPELINE-TEMPLATE stages 2–3.
- How Cape Jones uses it RIGHT NOW: `PIPELINE-TEMPLATE-20261031.md` stages 2 (storyboard)
  and 3 (animatic) are written with tool/file/gate per stage; `animatic_builder.py` exists
  in the rig (cited as wired in INDUSTRY-STANDARDS-PULL-20261031.md); per-shot timing
  already exists in `SHOT-SPECS-V6-20261031.md` (punch windup F1 hold 6, snap F7, impact
  F9 hold 12, recover F21; walk contacts on 12-frame holds; dance on 12-frame holds).
- Still missing: drawn storyboard panels for 30/30 shots (0/30); an animatic assembled
  from those panels with sound (0/1).

## 2. Camera language — PARTIALLY WIRED
- What: shot sizes (wide / medium / close-up), angles (low = power, high = small, eye
  level = neutral), lens feel, and moves (pan, dolly, track, tilt) chosen to stage the
  action, not decorate it. Source: standard cinematography for TV animation (Blain Brown /
  standard shot-language practice).
- How Cape Jones uses it RIGHT NOW: layout passes exist for room (locked 2.5x, 950px,
  chair back at waist, seated rule 2.5x → 2.3x), plus single-scene layout passes for
  flying, rooftop, alley, desk (`showcase/layout-pass-*-single-20261031.jpg`); room scale
  is the staging anchor for every room shot.
- Still missing: a camera-move sheet per shot (0/30); a shot-size list per scene (0/30).
- Presentation: [02-camera-language.png](sandbox://workspace/cape-jones-rig/tv-production-stack-20261031/02-camera-language.png)

## 3. Editing / cutting standards — PARTIALLY WIRED
- What: cut on action (cut mid-movement so the eye follows through), L-cut (audio from
  the next shot starts early) and J-cut (audio leads picture), pacing by hold length,
  24fps TV delivery. Source: standard film/TV editing practice (Walter Murch, In the
  Blink of an Eye; TV animation cutting on twos).
- How Cape Jones uses it RIGHT NOW: 24fps base, normal on 2s = 12 drawings/sec, fast
  snaps on 1s, holds 6–24 frames — all written in SHOT-SPECS-V6; the punch spec is
  already a cut-on-action spec (windup → snap → impact hold 12 → recover).
- Still missing: one edited sequence assembled from clips (0/1); L/J-cut decisions per
  scene (0/30).
- Presentation: [03-editing.png](sandbox://workspace/cape-jones-rig/tv-production-stack-20261031/03-editing.png)

## 4. Sound design + mixing standards — PARTIALLY WIRED
- What: three layers kept separate — dialogue, SFX, music bed — mixed to a delivery
  loudness, stereo for TV now, 5.1 as a later deliverable, with a cue sheet tying every
  sound to a frame. Source: TV mixing practice (ATSC A/85 loudness practice; -14 LUFS
  streaming/TV delivery target already adopted here).
- How Cape Jones uses it RIGHT NOW: `showcase/audio/audio-cue-sheet-v2.csv` + `.json`
  (3/3, 5 cues at 24fps), demo tones delivered as a link (`cape-jones-audio-cues-demo.mp3`),
  delivery target −14 LUFS, FFmpeg LUFS check wired in the audio spec.
- Still missing: SFX layers (0/1), dialogue recording (0/1), music bed (0/1), recorded

## 5. Lip-sync standards — PARTIALLY WIRED
- What: phoneme → viseme mapping timed to the audio waveform, one mouth drawing per
  phoneme beat, mouth frame = audio frame at 24fps, with holds on vowels and snaps on

  on twos) applied to the pack4 phoneme list.
- How Cape Jones uses it RIGHT NOW: `pack4-20261031/visemes/` 14/14 = 100% (rest, EE,

  (`pack4-20261031/proofs/proof-visemes-on-head-20261031.png`).

## 6. Background painting standards — WIRED (pieces)
- What: one-point/two-point perspective, a colour script (one palette per time of day /
  mood), and one consistent light direction and shadow side across every background in
  a scene, so a character can walk from room to street to forest without the light
  flipping. Source: standard background-painting practice (Disney background / colour
  script practice; TV layout colour keys).
- How Cape Jones uses it RIGHT NOW: 15 painted backgrounds kept (`backgrounds/batch-*`,
  1168×784, Mars 2026-10-31 "keep ALL"); 4 new painted backgrounds 20261031
  (`showcase/backgrounds-new-20261031/` — flying, rooftop, alley, desk); colour script
  carried by the 70 approved LUTs + JOJO-ATMOSPHERE (background shifted warm/purple,
  character base palette unchanged); light/shadow consistency carried by Level 2 v2
  (directional rim, bleed, ground shadow).
- Still missing: a light/shadow consistency check run per background (0/19); a written
  colour script sheet per scene (0/4 scenes).
- Presentation: [06-background-painting.png](sandbox://workspace/cape-jones-rig/tv-production-stack-20261031/06-background-painting.png)

## 10. Quality control / broadcast QC — WIRED (gates as tools)
- What: a QC checklist run before delivery — colour (grey control on every grade),
  audio (loudness + sync), legal (barred items: likeness / character / name / dialogue /

  warning, on a failed gate. Source: broadcast QC practice (network QC checklists).

  "labels are debug only" rule; "never recolour base art" rule.
