# COLORED SHADOW — mechanic / preset (Mars, 2026-10-31 ~18:29 CDT)

Saved as a mechanic AND a preset, per Mars. He is NOT a stand user.
This is not a JoJo Stand, not a character, not a second person.

## What it is, in plain words
A COLORED SHADOW: a flat, single-colour silhouette of Cape Jones's OWN rig,
standing behind him, that acts like a stand and does its own thing behind him.
What you see behind him in the stand-pair poses is exactly that — a purple
silhouette, nothing else.

- Colour: dark purple (52,22,90), flat, no detail, no face, no costume lines.
- Shape: his own rig pieces, same pose language, never a show character.
- Position: BEHIND him, offset behind (stand-01: +180px), never in front of him
  unless a future beat explicitly calls for it.
- Behaviour: it mirrors him sometimes (stand-01: same flex angles), and it does
  its own thing other times (stand-02: arms up while he crouches forward —
  the shadow does the exaggeration, he stays grounded).

## Why it is called that
Mars's own naming, 2026-10-31: "like a colored shadow that acts like a stand
and does its own thing behind him" / "what you call it, a purple silhouette,
that's about it." So the preset name is COLORED SHADOW, and the current
colourway is the purple silhouette. Future colourways are just a colour change
on the same mechanic, not a new character.

## How to use it (preset)
- Preset name: COLORED SHADOW
- Source: Cape Jones's own v7c rig pieces, flattened to one colour.
- Default colour: purple (52,22,90).
- Default staging: behind, offset +180px, mirrored pose.
- Variant: towering / exaggerating — shadow arms up (-150/150), user grounded.
- Layer order: shadow behind the user, user in front. (The face/cowl snap rule
  for the USER's own arms is separate — see ARM-FRONT-SNAP-RULE.md.)

## Future use — stand-user behaviour, without making him a stand user
If a future beat ever wants somebody to ACT like a stand user, the same
mechanic scales: put the OTHER character's rig behind them — the other rig,
or the other character's FLA rig pieces, staged behind as their coloured
shadow — so that other character reads as the stand-like companion.
That is a staging choice for that beat, not a change to Cape Jones's canon.
He stays not-a-stand-user; the coloured shadow is the tool that lets any
character get that read when a beat wants it.
