# Dual-orientation methods wired in this fix — run vs mapped, honestly

Original spec already had 3 forms. This fix adds at least 10 more.
RUN = code in this folder actually produced a file with that method.
MAPPED = industry tool named, principle mapped to our builder, NOT run
here, no trial / vendor run claimed. No method is listed as run unless
a file in this folder proves it.

## Already in the original spec (kept, re-tested at room scale)
1. Open-gate / protected master — RUN, and FAILED at room scale.
   Centre-crop protected master cuts a 1165px figure (head 35px,
   feet 50px). The failure is the finding, not hidden.
2. Auto-reframe (Premiere Auto Reframe, Resolve Smart Reframe,
   Final Cut Smart Conform) — MAPPED, not run. Trials blocked
   (Adobe sign-in pending, Smart Reframe is paid Studio, Smart
   Conform is Mac-only). Principle mapped: subject-bbox-tracked
   window, implemented in code as the tracked-crop check below.
3. Dual-canvas / multi-format timeline — RUN as one master, N exports
   in build_room_scale.py (master, portrait, landscape, square).

## New in this fix
4. Pull-back / two-framing — RUN, RECOMMENDED. Landscape is a
   dedicated 1920x1080 framing at the same 60.7% relative scale,
   not a figure-only shrink. File: landscape-room-scale-1920x1080.
5. Floor-plane anchor — RUN. Feet y is fixed to the rug plane
   (master 1550, landscape 924), not centred. Gate enforces it.
6. Scale-by-furniture — RUN. Scale is set by frame proportion
   (60.7%) from the locked layout, cross-checked against rug
   top (1371) and chair feet (1518) in the master.
7. Resize-not-crop (pull-back square) — RUN. Square is a resize
   of a 1165x1165 master window, labelled pull-back, not a crop.
8. Blurred pillarbox — RUN. portrait-blurfill-room-scale, from
   the new landscape. Backup only, subject smaller in portrait.
9. Subject-bbox tracked crop — RUN in code (figure bbox computed
   from alpha, checked against every crop; blind-crop cut math
   from the original spec is kept and re-run for the new bbox:
   a 607px blind centre crop of the new landscape would cut
   arms, because the new figure is 734px wide in the master).
10. Safe-area overlay proof — RUN. Portrait organic safe box
    (97,288)-(842,1482) and landscape title/action safe drawn on
    proof overlays only, never in clean exports.
11. Open-gate aspect markers — RUN. Master diagram draws landscape,
    portrait, and protected windows plus rug-top and feet lines.
12. No-crop / overscan — RUN, from the no-crop rule: all new
    canvases are sized to the figure, never the figure to a window.
    No figure alpha touches a canvas edge in the new proofs
    (checked by the builder's bbox math; square pull-back is a
    resize, not a clip).
13. FFmpeg H.264 still-to-video — RUN, if ffmpeg is present.
    Command pattern from the original spec, 2s, 24fps, 8Mbps,
    applied to the new landscape/portrait stills (see report;
    if ffmpeg was absent in the run environment, this line is
    corrected in the report and no video is claimed).
14. Premiere Pro Auto Reframe — MAPPED (see 2).
15. DaVinci Resolve Studio Smart Reframe — MAPPED (see 2).
16. Final Cut Pro Smart Conform — MAPPED (see 2).
17. CapCut auto-crop / multi-format export — MAPPED, not run.
    Principle: one timeline, auto-crop per ratio, subject tracking.
    Our tracked-crop code is the free equivalent, labelled as such.
18. Opus Clip / Vizard / Kapwing Smart Crop — MAPPED, not run.
    Principle: AI subject detection + auto-reframe. No upload,
    no account, no claim that they were used on Cape's art.
19. Adobe Express / Premiere multi-sequence resize — MAPPED.
20. YouTube Shorts auto-layout / TikTok auto-crop — MAPPED.
    Platforms re-crop on upload; our safe boxes are the defence
    against that, not a claim that platform tools were run.
21. Broadcast centre-cut / protected-area practice — RUN as a
    principle: the protected square is kept as a composition
    guide, but at room scale it is explicitly NOT sufficient,
    which is why pull-back framing replaces centre-cut here.
22. Two-camera / two-framing shoot practice — RUN, same as 4,
    stated separately because it is the production answer:
    shoot the landscape framing and the portrait framing as
    two framings of one room, not one crop pretending to be both.
