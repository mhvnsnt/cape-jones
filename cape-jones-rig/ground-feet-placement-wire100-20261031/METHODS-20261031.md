# METHODS — ground / floor-plane / contact, run vs mapping

## RUN in this folder (code in ground_gate.py, measured on the proofs)
1. World ground line anchor — layout ground line, Disney / stage practice.
   BARS Gy=700, size ground y=1500, room master feet 1550. RUN: gate
   checks feet_y against an explicit line, measured from pixels.
2. Furniture / reference-object anchor — chair anchor from the portrait
   gate (chair 818 px scene, figure/chair 1.424 locked). RUN: rug-mode
   gate is checked alongside the furniture ratio in the portrait gate;
   this gate re-uses its rug band, it does not re-derive the chair.
3. Rug / floor-plane position — feet position down a rug/floor band.
   RUN: rug_position formula above, planted band [0.55, 0.95].
4. Contact shadow grounding — separate labelled shadow layer under the
   feet, blurred, drawn under the figure, never baked into base art.
   RUN as a cue: shadow_cue measures dark px, top, gap, ground-band
   presence. Limitation, stated: synthetic ground line confounds it,
   and the first shadow window (feet+120 px) missed the airborne shadow
   at the ground line — corrected to also check the ground band.
5. Alpha-bbox feet measurement — feet = alpha > 10 bbox bottom on a
   plate, or diff > 20 + light > 170 + diff > 50 on a composite.
   RUN: apose plate 248,253-875,1294, 373,846 px; resized proof figure
   142,145-504,746, 127,621 px. The diff > 50 floor was added after the
   first airborne proof miscounted a blurred shadow feather over light
   sky (diff 17-30, mean > 170) as a foot at y698 instead of the true
   520. Corrected, not hidden.
6. Per-frame sequence consistency — feet spread, world centre-x spread,
   height-trajectory smoothness. RUN: BARS, size walk, size power, and
   the new 5-frame walk all PASS with spread 0.
7. Floor-plane perspective grid — converging lines to a vanishing point,
   floor only. RUN: synthetic bg grid, vanishing point (550,430), lines
   clipped to y >= ground. First draft drew the grid through the sky;
   corrected to repaint the sky above the ground line.
8. Parallax depth cue — foreground/background move at different rates
   (BARS 0.3 / 1.0 / 1.8), so a grounded figure stays on its world line
   while the camera moves. RUN in the sense that BARS measurements are
   re-gated here; the parallax builder itself is not re-run.
9. Height-from-shadow cue — airborne: shadow detached from the feet,
   on the ground line, smaller / blurrier with height. RUN: G3 shadow
   on the ground, ground-band dark 2,190 px, ground gap 186 px measured
   (stated height 180 px, 6 px fringe).
10. Spec-mode enforcement — GROUNDED vs AIRBORNE label is required in
    every spec, no silent default, airborne-without-height FAILS,
    airborne-with-feet-on-ground FAILS as a spec mismatch. RUN in code.

## MAPPINGS only, with exact reason not run
- Blender camera / ground-plane tracking: no Blender render was run in
  this task; the BARS Blender scene (camera + 3 planes) already exists
  from the multiplane upgrade, but no new Blender ground render is
  claimed here.
- After Effects / Premiere ground-plane / 3D camera tracker: vendor
  tools, no trial run in this task; the method is the same anchor +
  parallax principle, implemented in PIL above.
- OpenCV / MediaPipe pose foot keypoints: no model run; alpha-bbox is
  the run proxy. Keypoints would give left/right foot separately,
  which alpha-bbox bottom (lowest foot) does not — that is a stated
  limit: a walking pose with one foot raised still has its lowest foot
  on the ground line, so the gate passes it, but it cannot verify the
  raised foot's height by itself.
- Depth Anything / MiDaS floor depth: no model run; depth here is
  measured rug position and ground-line offset, not a learned depth map.
- Toon Boom Harmony / Animate stage ground peg: trials blocked at the
  time of the earlier comparison work; no stage-scale run is claimed.
- AI depth / learned bbox: no model run; auto-detect here is a row-
  gradient edge, not a learned model, and its confidence is low on a
  busy painted room (KKGuh 0.155) — which is why it is ESTIMATE only.
