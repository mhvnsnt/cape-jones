# SHOW-BUILDING METHOD — Cape Jones, and Mars's other shows (Mars, 2026-10-31 15:27 CDT, standing)

This is how we build this show for now, and how we build a lot of Mars's shows. Logged at Mars's instruction, 2026-10-31.

## The method, in one line
Placeholder character -> kitbash + reskin -> redesign -> a completely different, original character.

## What each step means
- PLACEHOLDER / TEST / STAND-IN: a character used only to test a scene, movement, or timing. In games this is temp art / greyboxing. It never ships as-is.
- RESKIN: surface change only — new colors, new textures, same model/silhouette/parts underneath. A palette swap is a reskin.
- KITBASHING: taking parts from existing assets and combining them into something new.
- REDESIGN / REWORK: colors + parts + silhouette all changed until it is a different character entirely. That is the shipped result.
- Art style staying similar does NOT make it their character. Style and character identity are separate things — two characters can share an art style and be completely different characters, the same way two shows from the same studio look similar but are not the same cast.

## The reference style (Mars's framing)
Robot Chicken style, a little bit. Like South Park, Family Guy, Simpsons — shows that use existing characters, formats, and pop culture as reference material and transform it into something of their own. That is the intent here: reference + transformation, not theft.

## What this is NOT
This is not stealing their content, not stealing from their show, not stealing their characters. Nothing ships as their character.

## Barred list — the ONLY things barred (Mars, 2026-10-31 15:23-15:24 CDT)
1. Exact character likeness image, shipped as-is
2. Using their character literally
3. Character name
4. Dialogue literally from their script
5. Brand image / logo

Everything else is pullable: any type of move, any system, any timing, any pose, any rig structure, any production method.

## Character-image exception
A character image may be brought over ONLY as a production reference, and ONLY if it is edited/modified during production into a parody character or a whole different character before release. It must not ship as their character. Reference material in the audit is flagged TRANSFORM-ONLY for this reason.

## Applies to
Cape Jones first (gate order unchanged: prove good shots with Cape Jones alone first, then other shows, then more characters), and then to Mars's other shows built the same way. This doc is the standing method for all of them until Mars changes it.
