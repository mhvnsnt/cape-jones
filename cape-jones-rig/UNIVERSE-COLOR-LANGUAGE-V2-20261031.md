### 1b. Public research — Araki / David Production (deepened)
Sources (public, colour methods and palette theory only; no
character art, dialogue, or logos copied):
- Araki: "None of my characters have a canon color palette."
  Colours change by scene for action, suspense, drama, excitement.
  The manga was mostly black-and-white, so readers imagined hues
  freely; the anime honours that with shifts. Covers vary freely
  (one cover one scheme, the next another) — variability IS the
  method, not a mistake in it.
- Gauguin / Synthetism / Cloisonnism (Araki's cited root): colour
  liberated from its descriptive role — large flat areas of intense,
  non-naturalistic hue, separated by strong outlines, chosen because
  they look good together and evoke emotion (soft pink grass against
  dark horses). Synthetism = observation + memory + imagination +
  feeling, synthesised. This is the direct ancestor of Dialect 2:
  a shift is not "wrong colour", it is colour freed from
  description and put to work as feeling.
- Fauvism (Matisse, Derain, Vlaminck): colour as pure expression,
  intense juxtapositions placed side by side so the eye vibrates —
  tension and power felt in the nervous system before it is
  understood. Vlaminck: "I heightened all my tonal values and
  transposed into an orchestration of pure color every single thing
  I felt." Dialect 2 rule drawn from this: a shift must be BOLD
  enough to be felt, or it reads as a grading accident. A 5%
  nudge is not a JoJo shift; a named palette jump is.
- David Production: shifts use APPROVED palettes, not random
  per-frame colours. Shifts appear in opening songs and at dramatic
  moments; whole scenes bathed in pink or turquoise (Part 5); a
  character's look in an opening may follow a volume-cover palette
  rather than the episode default. A victory beat may go chic
  black-and-white. Morioh (Part 4) is the environment case: yellow
  skies, purple hills, pink grass in a seemingly normal town —
  "incorrect" colours creating unease, not a mistake.
- Inverted schemes: time stops, deep thought, power-ups get
  inverted schemes and ominous red tints. Complementary opposition:
  in a climax, one side's hair turns red against the other's green
  — opposition ON the colour wheel, not two random colours.

### 1c. Public research — colour theory / TV grading (industry-standard)
- Warm / cool psychology: warm (red, orange, yellow) = passion,
  energy, warmth, excitement, danger; cool (blue, green, purple) =
  calm, mystery, melancholy, trust, isolation; neutrals (white,
  black, grey, brown) = balance or uncertainty. Warm-shifted images
  signal warmth, nostalgia, safety; cool-shifted signal tension,
  drama, isolation (Elliot, University of Rochester, colour-affect
  research, widely cited).
- Complementary (opposites on the wheel) = maximum contrast and
  visual tension, draws the eye; orange–teal is the blockbuster
  default for exactly this reason, and because human skin is
  orange-toned, cooling everything else makes the figure pop.
  Split-complementary = base + the two colours adjacent to its
  complement: same strong contrast, less tension. Triadic = three
  evenly spaced hues: vibrant even in pale versions. Analogous =
  adjacent hues: harmonious, cohesive. Monochromatic = one hue in
  tints/shades: unified, low conflict.
- Colour script (Pixar / animation production standard): colour
  thumbnails mapping colour, lighting, emotion and mood across the
  whole film, evolving with the story — NOT a single pretty frame.
  A film's colour works best when it follows a clear path from
  start to finish. V2 adopts this: Dialect 2 palettes are a SCRIPT
  (section 4 trigger table), not a bag of filters.
- Value over hue: value (lightness) matters more than hue to a
  design's success; most images use a wide array of tones, not pure
  hues. Skin-tone integrity is non-negotiable even in moody grades;
  memory colours (skin, grass, sky as the viewer expects them)
  are what a shift deliberately breaks — and must break on purpose,
  by name, or it reads as an error.
- Temperature in Kelvin (from RIM-COLOR-RULE.md, kept): tungsten
  warm 2700–3200K reads orange/intimate; daylight 5500–6500K reads
  blue-white/cold. A shift that changes temperature changes mood
  even before hue is noticed.
- TV finishing (already in the stack, kept): L5 finishing =
  Rec.709, gamma 2.4 output; 33-point .cube LUTs; ACES/OCIO in a
  colour-managed tool (still owed as a viewed test — see section 6).

## 2. The dialect system, deepened

DIALECT 1 — LIGHTING-MOTIVATED (unchanged from v1, plus corrections).
Colour comes from a light source in the scene: LUT, grade, key /
fill / rim, bleed, shadow. Rim follows the key within ±20° hue.
Dual-light / tertiary: a SECOND named source from behind (cyan)
radiating as god rays, with its own rim. CORRECTION (Mars, 15:48
CDT): cyan backlight god rays apply ONLY when cyan rim + gold
LUT/overlay are combined. Gold rim alone gets NO cyan backlight.
NEW NUANCE (Mars, 15:53 CDT): when cyan comes from behind, the
front may ALSO mix — gold rim WITH cyan rim AROUND it, layered
(see DUAL-LIGHT-RIM-MIX workstream; v2 does not pre-approve any
rim-mix variant — Mars picks from the variant sheets).

DIALECT 2 — JOJO NON-CANON (deepened). Colour changes though no
light in the scene changed, to create a scenario, vibe, atmosphere
or feeling. It may run alone OR combined with Dialect 1 (record
BOTH: grade + shift + rim under shift). Deepened rules, all new
in v2:
1. TRIGGER FIRST, STILL. Beat, feeling, palette, scope, duration,
   return — in the shot spec before use. No trigger = no shift.
2. BOLD OR NOTHING. A shift must be a palette jump the eye feels
   (Fauvism rule). A timid nudge is a grading error, not a shift.
3. COOL FIRST, NEVER A LECTURE (from Mochiichao representation
   canon). A shift shows a feeling in colour; it never announces
   it in words, and it never exists only to label a character.
4. SHOW-FIRST, ALWAYS. Every new palette is demo-only until Mars
   approves it by name. Approval of the demo SHEET is not approval
   of every palette on it for canon use — see section 5.
5. COLOUR SCRIPT, NOT A BAG. Palettes are ordered along the story
   (section 4). Two shifts in a row must be chosen as a PATH
   (e.g. tension -> dread -> power -> base), not at random.
6. RETURN IS PART OF THE SHIFT. Every shift ends: back to base, or
   into the next named shift, in a stated number of frames. A shift
   that never returns is a continuity break, not a style.
7. VALUE AND SKIN. A shift keeps value structure readable and
   skin tones recognisable unless the shift IS the break (near-B&W
   uncertainty is the named exception, and it is named as such).
8. SCOPE IS A CHOICE, NOT A DEFAULT. Character-only, environment-
   only, or both — recorded per shift. Atmosphere is environment-
   only by definition; a character-only shift never touches the sky.
9. OPPOSITION IS A PAIR. A confrontation pair is recorded as one
   entry with two hues, never as two independent shifts that might
   drift apart.

## 3. Palettes, deepened (8 entries + base)

Each entry: trigger, scope, duration, return, gain (grade used on
the presentation sheet; production = 33-point .cube per palette,
still owed — gains are NOT claimed as .cube LUTs), rim, bleed,
shadow, colour-theory grounding, and what it must never be used for.

BASE — canon. No shift. Gain (1.0,1.0,1.0). Rim warm amber
(255,180,80) under golden-hour grade, or neutral white under
neutral grade. Every shift returns here unless the script says
otherwise. APPROVED (base palette itself, 2026-10-31).

JOJO-TENSION — purple/pink family. Trigger: uncertainty rising,
a threat not yet named, a decision approaching. Scope: character
+ environment, or character only. Duration: 12–48 frames, then
escalate (to DREAD or POWER) or return. Gain (1.20,0.70,1.30).
Rim magenta-rose (255,178,229), bleed (220,60,160), shadow cool
violet. Grounding: purple = mystery + cool tension; pink = the
Fauvist intense juxtaposition; split-complementary to the warm
base. Never for: a calm scene, a joke beat (it will read as dread).
Status: DEMO-ONLY for canon (demo sheet approved 15:49 CDT is
approval of the sheet as a demo, not canon approval of this
palette — Mars approves each palette separately).

JOJO-POWER — red family. Trigger: power activation, climax,
a strike landing. Scope: character + environment flash, or
character only. Duration: 6–24 frames burst, then return to base
on the hold. Gain (1.30,0.60,0.60). Rim (255,120,110), bleed
(220,40,40), shadow deep red-black. Grounding: red = passion,
energy, danger, aggression; the warm extreme of the wheel.
Never for: a quiet or tender beat. Status: DEMO-ONLY for canon.

JOJO-UNCERTAINTY — near black-and-white, high contrast. Trigger:
a character unsure of themselves, hero or villain, a moment where
the colour itself says "I don't know which way this goes".
Scope: character + environment. Duration: 24–72 frames, then
return or resolve into RESOLVE or POWER. Grade: desaturate to
~15% colour + contrast 1.15. Rim white (255,255,255), bleed grey
(128,128,128), shadow black. Grounding: neutrals = balance or
uncertainty; removing hue removes the memory-colour anchor, so
the viewer feels the unmooring. This is the David Production
uncertainty use (a victory beat in black-and-white). Never for:
a scene that needs hue information (e.g. a colour-coded clue).
Status: DEMO-ONLY for canon.

JOJO-ATMOSPHERE — environment-only. Trigger: a place that feels
wrong, surreal, or dreamlike while the character is normal — the
Morioh use. Scope: ENVIRONMENT ONLY, character gain (1.0,1.0,1.0)
always. Duration: a whole scene or sequence. Environment gain
reference: yellow sky (230,200,60), purple hills (130,70,170),
pink grass as needed. Rim: base key rim (warm amber under
golden-hour), because the character is unchanged. Grounding:
environment shifts break memory colours (sky, grass) while the
figure stays anchored — unease without confusion about who he is.
Never for: changing the character's colours by accident (that is
a different shift, and must be named as one). Status: APPROVED
(Mars, 2026-10-31 15:36 CDT, reply to the yellow-sky image).

JOJO-DREAM — pink/turquoise whole-scene bath. Trigger: a
fantastical, operatic, or heightened sequence; an opening-style
moment; a scene that should feel like a volume cover come alive.
Scope: both, whole scene. Duration: a whole scene or sequence.
Gain (1.15,0.80,1.20) on the character reference; environment
turquoise counterweight. Rim pink (255,170,220), bleed
(230,90,190), shadow purple-teal. Grounding: Part 5 whole scenes
bathed in pink or turquoise; triadic vibrancy; Fauvist pure-colour
orchestration. Never for: a grounded, realistic beat (it will
break the room's reality). Status: DEMO-ONLY for canon (new in v2).

JOJO-DREAD — ominous desaturated red. Trigger: time stopping,
deep thought, a power-up with menace, a moment going wrong.
Scope: character + environment. Duration: 12–36 frames, then
return or escalate to POWER. Gain (1.05,0.60,0.60) darkened 0.85.
Rim dark red (200,70,70), bleed (150,20,20), shadow near-black.
Grounding: inverted-scheme family; red tint + darkness = the
ominous end of the warm scale; value dropped so the scene feels
heavier, not just redder. Differs from POWER: POWER is bright
and explosive; DREAD is dark and held. Never for: a triumphant
beat. Status: DEMO-ONLY for canon (new in v2).

JOJO-RESOLVE — cool teal. Trigger: calm after uncertainty, a
decision made, trust, a clear head. Scope: character, or both.
Duration: 24–96 frames, often the RETURN path out of UNCERTAINTY.
Gain (0.75,0.95,1.20). Rim teal-cyan (150,220,230), bleed
(40,170,190), shadow cool blue. Grounding: cool = calm, trust,
stability; complementary to the warm base, so the shift reads as
a deliberate cooling, not a mistake; split-complementary softness
keeps it from fighting the figure. Never for: a high-tension
beat (it will deflate it). Status: DEMO-ONLY for canon (new in v2).

BRIGHT PINK JOJO TENSION / PINK HOUR JOJO TENSION — the approved
combined image, renamed. Trigger: golden-hour grade + tension
shift combined, reading bright pink in the final image. Scope:
character + environment as in the approved image. Gain
(1.25,0.70,1.10) on the reference sheet. Rim pink family.
Grounding: Dialect 1 + Dialect 2 combined, recorded as BOTH
(grade + shift), per v1 rule 4. NEVER call this "golden hour"
— Mars, 15:50 CDT: it is bright pink, so it is Bright Pink /
Pink Hour JoJo Tension. Status: APPROVED as that image
(Mars, 15:49–15:50 CDT). The name approval does not canon-approve
every pink grade; it approves this image and this name.

JOJO-OPPOSITION — a PAIR, not a palette. Protagonist red gain
(1.30,0.60,0.60), rim (255,110,100); antagonist green gain
(0.65,1.15,0.70), rim (110,230,140). Trigger: a confrontation
where the two sides must read as opposites at a glance. Scope:
both figures, for the duration of the confrontation, recorded
as ONE entry. Grounding: complementary opposition on the wheel
— maximum contrast, instant visual hierarchy. Never as two solo
shifts. Status: DEMO-ONLY for canon (pair sheet is a reference,
not a scene; no antagonist exists in Cape Jones canon yet).

## 4. Trigger table — the colour script (path, not bag)
Story beat -> palette -> scope -> duration -> return.
- Calm house, lights, TV, games -> BASE -> — -> — -> —
- Something feels off, threat unnamed -> TENSION -> char+env ->
  12–48f -> DREAD or POWER or BASE
- He is unsure which way it goes -> UNCERTAINTY -> both ->
  24–72f -> RESOLVE or POWER or BASE
- A place feels surreal while he is normal -> ATMOSPHERE ->
  env only -> whole scene -> BASE
- Power activates, strike lands -> POWER -> char (+env flash) ->
  6–24f -> BASE on the hold
- Time stops, deep thought, menace -> DREAD -> both -> 12–36f ->
  POWER or BASE
- Decision made, calm, trust -> RESOLVE -> char/both -> 24–96f ->
  BASE
- Operatic, fantastical sequence -> DREAM -> both -> whole scene
  -> BASE
- Confrontation, two sides -> OPPOSITION (pair) -> both figures
  -> confrontation -> BASE (both figures together, never one
  returning alone without a recorded reason)
- Golden grade + tension combined -> BRIGHT PINK JOJO TENSION ->
  char+env -> as approved image -> BASE
