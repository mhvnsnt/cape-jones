## Correction to the task wording, stated plainly (not hidden)

The baked artefacts were NOT "red joint dots". They were the rig's fixed-position
debug labels: 4 red numbered circles (ARM 1, ARM 2, LEG 1, LEG 2) at plate coords
(340,430), (760,430), (400,820), (700,820), plus red "ARM 1/2", "LEG 1/2" text —

character joints (circle-masked caps from the rig pieces) and STAY: they are
visible in every clean plate and every re-render, unchanged in kind.

The old endtoend finals' workaround converted those red label circles to WHITE
circles, same geometry — so the old finals still carried white label circles
on the torso/legs (clearly visible in before-after-shots-20261031.png, e.g.
CJ-01 shoulder, CJ-04 both shoulders). The true fix here is not a recolour:
the plates were re-rendered from the rig with labels off, so the label zones
now show the underlying art (where a label overlapped the figure) or
transparency (where a label floated over background — e.g. the ARM-2 circle

## Two honest deltas Mars should know (not hidden in the "plate swap" label)

1. CJ-03 / CJ-05 — label-only, 0 px outside the label mask. The v7c clean
   render matches the labelled v7c source exactly outside the geometric
   label mask (4 circles r32 + 4 text boxes). CJ-03/CJ-05 clean RGB renders
   are byte-identical (same SHA) to the clean-100 renders of the same poses,
   independently reproducing that batch. Their large final diffs
   (195,587 / 211,758 px) are NOT new art: the old crop was 5px wider
   (789 vs 784) because the ARM-2 label circle protruded to x789 while the
   true figure ends at x784 — so the old figure was scaled from a 789px-wide
   crop and the new one from a 784px-wide crop (final char 656 -> 652px,
   -0.6%). A ~2px resampling shift across a line-art figure counts many
   pixels as "different" even though the pose, colours and BG are unchanged;
   diff outside the expanded char union is 0 for both. CJ-05's effect count
   moves 18,464 -> 18,372 px for the same reason (placement-glow ellipse
   radius scales with char width).
2. CJ-01 / CJ-02 / CJ-04 — labels + a v7b->v7c rig refinement, disclosed.
   Their labelled sources were built with the v7b rig (clips-v7), not v7c.
   Proof: a v7b build with its label block stripped matches each labelled
   source EXACTLY outside the label mask (0 px: CJ-01 10,603 px diff all
   inside the mask; CJ-02 10,484; CJ-04 10,618 — those control renders are
   saved in control-v7b-stripped-NOT-plates/, labelled NOT plates, never
   used as shot plates). The delivered v7c clean plates therefore differ
   from those sources by 25,903 / 25,944 / 26,847 px outside the label mask
   (1.57% / 1.57% / 1.63% of the plate) — the v7b->v7c ball-centre joint
   refinement (cut-limbs-v7c, ball-centre pivots, trimmed upper stubs),
   with pose angles identical. This is the standing clean standard
   (v7c labels=False, same as punch-09 clean and clean-100), so the punch
   family is now on one rig version — but Mars's eye is the judge: if he
   wants the v7b joint geometry preserved pixel-for-pixel for these three,
   the v7b-stripped controls exist as the fallback, and that would be a
   different, explicitly-labelled plate set, not a silent swap.
