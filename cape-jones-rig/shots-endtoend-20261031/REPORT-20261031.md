## Method (so the next lane can swap a layer without rebuilding the shot)

- Character: transparent plates from transparent-plates-sweep-20261031 (true alpha). Baked showcase/layout/composited images were REJECTED as backgrounds because they already contain the character + red debug dots and would double-print him.
- Feet anchor: alpha-bbox bottom placed on the world ground line (grounded) or above it by the stated height (airborne), with a flight line at feet level in the proof file only. Proof files carry ground/flight lines; finals carry NO labels.
- Shading axis: character-only LUT gain (spec gain per shot; CJ-01/02 tension gain 1.2,0.7,1.3 on character only, BG on base golden-hour; CJ-26 uncertainty desat near-B&W) + outer rim band 4px in spec rim colour + inner bleed band 6px at 35% bleed colour. Dual-light CJ-19/CJ-30: rim split left=front source, right=back source, both sources named in the JSON note.
- Multiplane axis (4 planes every shot): far BG plane (blurred) + mid BG plane (1.07x, +24px offset, ground band) + character + foreground strip (blurred BG, 30% alpha, in front of feet). Painted shots use a real painting for far/mid; script shots use a colour-script gradient + silhouette mid-plane.
- Shafts axis: Level 3 = 6 shaft wedges in rim/key colour (dual-light: alternating front/back colours), blurred, behind character. Level 2 = 0 shafts, verified (shaft layer empty). This is separate from the 4 shafts presets lane (V2/V3/V3+pools/Glare) — those presets were NOT merged into these shots.
- Effects axis: one named, measured effect layer per shot (impact burst, dust, sparkles, rings, speed lines, aura, gauntlet glow, halo, shout burst, flare, bokeh, neon rings — see table). Effect px is the measured alpha>10 pixel count of that layer.
- No-crop: non-room char 880px tall, ground 950 (1080 canvas). Airborne shots expanded upward (CJ-12 1920x1170, CJ-13 1920x1220, CJ-14 1920x1200, CJ-15 1920x1190, CJ-21 1920x1150) so head + glow stay inside. Room shots 1920x1280, ground 1180: standing char 1140px (950px rig at 2.5x scaled to 3.0x), seated char 1034px (= 1140 x seated/standing bbox ratio 945/1042; seated 2.8x is DERIVED from the standing 3.0x minus the prior 0.2 seated offset, not directly ordered — Mars can correct it).
- Audio: cue IDs CJ-A01..CJ-A30 recorded only; no audio is claimed by a cue ID.
