## V2 clean method (run, in build_v2.py)
Mouth-material only: black (lip/cavity, all channels <80), white teeth (>200 all), tongue (r>100, g<135, b<95, r>g+25). Everything else dropped. Thick mouths (AH, GK, AH34, SMILE34): 5x5 opening removes thin face lines, 2px dilation keeps the lip outline. Thin-line mouths (MBP, MBP34, EE): component rule only — opening would erase the line itself. Placement, every mouth: single target (231.5, 504.5) — the better v1 position, left/down/0.75x — alpha-bbox centre anchor, scale = old fitted scale x 0.75. Measured per mouth in measurements-v2-20261031.json; no mouth jumps by construction (same target every mouth). Corner wrinkles: 0 kept, 0 added. If Mars wants a corner wrinkle for a specific viseme it is a labelled separate layer, still owed, not silently carried.
