## Side rig: FK chains, layer order, rules — built 100%

Chains (pivot = ball centre, v7c convention; PIL-CCW degrees, forward-left
= positive because a downward limb rotated CCW swings its foot left):
- spine: pelvis -> torso -> head
- arm_near: shoulder_n (600,460) -> elbow_n -> wrist_n -> hand_n
- arm_far: shoulder_f (652,460) -> elbow_f -> wrist_f -> hand_f
- leg_near: hip_n (600,1000) -> knee_n (1280) -> ankle_n (1542) -> boot_n
- leg_far: hip_f (616,1000) -> knee_f -> ankle_f -> boot_f
- cape: parented to torso/shoulders, backmost, rotation 0
- segment lengths: upper 260, forearm 260, thigh 280, shin 262. A straight
  leg plants the boot bottom exactly on ground 1600 (ankle 1542 + 58px
  boot below its ankle pivot; measured, not assumed).

Layer order, back to front: cape_drape, upper_arm_far, forearm_far,
hand_far, thigh_far, shin_far, boot_far, pelvis_belt, torso, thigh_near,
knee_cap_near, shin_near, boot_near, upper_arm_near, elbow_cap_near,
forearm_near, hand_near, head_cowl.

Rules wired in:
- Ground gate: planted boot bottom == ground 1600 within 3px; a swing
  boot is raised and stated, never faked flat.
- Knee-feet rule, profile form: toe-left boots require knees forward-left
  or straight, never behind the hip-ankle line (exception only: a
  deliberately broken leg named in the shot spec). An early draft bent the
  planted leg's knee backward (offset +15.9, toe-left) and the gate
  correctly FAILED it; the shipped walk-step keeps the planted leg
  straight and bends only the swing leg, forward.
- Wrist rule: hand pivots sit exactly on FK wrist joints (forearm ends);
  hands are never free-placed.
- No-crop gate: every piece bbox inside the 1200x1800 canvas.
- No-squash rule: nothing front was squashed into a side piece; the
  emblem is edge-on only.
