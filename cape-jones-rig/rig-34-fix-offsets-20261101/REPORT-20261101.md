## 10 industry math / rigging systems — wired 100%, all RUN
Builder: build_fix.py. Results: gates-math-20261101.json.
- M1 3/4 perspective projection: depth foreshortens by cos(45°) = 0.7071.
  100px front -> 70.71px at 45°. This is why a 3/4 piece is not a squashed front piece.
- M2 FK chain: end = joint + rotated (0, length). Shoulder->elbow->wrist,
  hip->knee->ankle, same as v7c limb().
- M3 Analytic 2-bone IK (law of cosines): given a wrist/knee TARGET, returns
  upper/lower angles. Run as a check on both elbows (see json).
- M4 Pivot / ball-centre math: ball offset = (ball_frac - 0.5) x width.
  L: (0.27-0.5) x 124.8 = -28.7px; R: (0.51-0.5) x 111.8 = +1.1px.
  Drawing substitution: sit-chair R forearm = forearm_hand_mid, spares saved.
- M5 Proportion / construction lines: head 196.3px, torso 314.6px, thigh L 266.5px
  (scaled x1.3); head = 12.27% of 1600px canvas height.
- M6 Foreshortening ratios (CJ-15 proof, standing record): forearm width x1.30,
  height x0.47, fist width x1.69, ratio 0.53. Not re-derived for this rig;
  used as the check that 3/4 foreshortening is a ratio, not a guess.
- M7 Layer / z-order (painter's algorithm): cape 0, thigh 1, shin 2, knee cap 3,
  pelvis 4, torso 5, upper arm 6, forearm 7, neck 8, head 9, arms-up override 10.
- M8 Ground-plane perspective: planted iff |foot_y - ground_y| <= 2px.
  Here L 1475 vs 1475, R 1475 vs 1475, PASS.
- M9 Scale / orthographic math: piece scale 1.3 (torso native 224 -> 291.2px);
  neck native 96px -> 101px at v7c scale 1.05, unchanged here.
- M10 Pose interpolation (smoothstep): t=0 -> 0, t=0.5 -> 0.5, t=1 -> 1.
  Example: pelvis dx at half-inbetween = -7 x 0.5 = -3.5px.
- Auto-offset solver (the point of the system): auto_offset(current, target)
  = target - current. Examples in json: pelvis (700,640)->(693,640) = (-7,0);
