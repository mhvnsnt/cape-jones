## What L5 is (all of L4, plus all five)
1. Crisp distinct shafts: hard-edged diagonal bands (2px feather,
   measured 10-90 edge width 2-3px on horizontal scans) over god-ray
   v2 — countable separate beams, not soft glow + bands.
2. Estimated-normal interior shading: per-pixel dot(normal, light)
   from the plate's own luminance gradient (shape-from-shading
   proxy; the L5 spec allows "normal/depth pass or estimated
   normals"). Gold light from the left, cyan from the right, clipped
   to plate alpha, 0.38 max. This is direction-based, not L4's flat
   gradient wash. HONEST LIMIT: it is NOT a true 3D-rebuild normal
   pass. A 3D rebuild would be the gold standard and is still owed
   if Mars wants it; the estimated pass is what is built and measured.
3. Side-weighted wrap: outer gold ring + spill alpha weighted 1.0
   (backlit left) -> 0.15 (front right). Measured on rim colours:
   gold pixels left mean R 230.6 vs right 205.7; cyan pixels 8340
   left vs 5926 right. Whole-ring mean brightness is nearly equal
   (177.0 vs 174.4) because bright background shafts dominate that
   zone — the side-weight shows in the rim colours, not in the
   background-dominated average. Stated, not hidden.
4. Full colour tracking: color-tracking-l5-20261031.json — every
   rim/bleed/shaft/spill colour with input + on-screen + cause.
   Gold rim median (216,165,146) vs input (255,180,80): shifted by
   gold-over-cyan + halo mixing; the seam pink (206,157,151) is the
   ACCEPTED V5 pinkish read. Suit white (250,250,250) = preserved.
5. Shot-to-shot consistency: the SAME script/stack rendered a second
   pose (apose) cleanly, and an identical-params re-render of the
   arms-up shot is PIXEL-identical (mean abs diff 0.0; file hashes
   differ only because Blender PNG metadata carries a timestamp).
