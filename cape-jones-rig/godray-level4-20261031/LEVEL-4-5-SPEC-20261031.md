## 2. LEVEL-NUMBERING RULE (Mars, 17:11 CDT, STANDING)
There are three levels in the original scale (L0–L3). If you create
something ABOVE the third level, LOG IT AS LEVEL 4. If you create
something above that, LOG IT AS LEVEL 5. As the lighting/effects
pipeline keeps upgrading, levels keep going up by the same rule.
Do NOT cap at L3. Do NOT call a higher mix "still L3".
Levels and preset packs are DIFFERENT axes (see §4) — a pack version
number is never a level number.

## 3. WHAT MAKES L4, WHAT WOULD MAKE L5

### L0–L3 recap (unchanged)
- L0: no lighting/effects.
- L1: LUTs / lighting only.
- L2: shadows + outer rim + colour bleed + colour key bleed, NO god rays.
- L3: god rays + rim + full effects. Gate (all required): (1) bright
  volumetric rays, not dark bands; (2) layered dual rim, named order;
  (3) bleed / light-effect bleed; (4) light affecting shadows — ground
  + cast + spill ON the character; (5) more effects — bloom/glare,
  haze, dust, colour-temperature contrast; (6) motivated light (every
  rim/bleed/shaft names its source and direction). Missing any = L2.

### L4 — beyond the V5 after (candidate built here)
L4 = ALL of L3, PLUS at least three of these, measured, not claimed:
1. Interior directional light ON the character, not just a rim band:
   light from the left/right sources lands on his body (wash clipped
   to the plate, direction-consistent). L4 candidate: gold wash from
   the left + cyan wash from the right, plate-alpha-clipped, 0.25 max.
   HONEST LIMIT: this is a 2D gradient wash, NOT normal-based shading.
   True pec/fold shading by surface normal is an L5 item.
2. Hard rim + soft rim double layer, kept distinct (Mars rim rule,
   corrected 17:05 CDT: "soft rim" and "soft halo" are the SAME thing
   in Mars's original usage — one soft layer, not two. The L4 double
   layer is hard rim + that one soft layer, sharp line + blurred halo
   under it, not merged into one blurry band. A soft-on-soft test is
   an EXPERIMENTAL variant only, not the default stack).
3. Colour-preserved rims: the rim colour that goes IN is the rim colour
   that reads ON SCREEN, or the shift is measured and logged (§5).
   L4 candidate uses Standard view transform, not AgX.
4. Foreground atmosphere / depth: dust/bokeh in front of the plate,
   haze separation between character, shafts, and background.
   L4 candidate: 90-dot foreground dust layer over the composite.
5. Gentler, controlled bloom: bloom that does not wash the rim out
   (L4 candidate: Glare fog glow threshold 0.80, strength 0.20, vs
   L3's 0.75 / 0.35).
6. Ground light interaction beyond a shadow: light pool / spill on
   the ground answering the shafts (partially in L3 via cast shadow;
   a full pool + reflection is still to be built per shot).
L4 GATE CHECKLIST (all must be checked, Mars decides the read):
[ ] L3 gate 1–6 all pass
[ ] ≥3 of L4 items 1–6 present, each named in the shot spec
[ ] Rim input colour vs on-screen colour measured (§5 fields filled)
[ ] Plate untouched (base art never recoloured; grade on background
    only, wash is a light layer, not a repaint)
[ ] approved_by_mars: false until Mars says it reads as L4

### L5 — beyond L4 (DEFINED, NOT BUILT)
L5 = ALL of L4, PLUS all of:
1. Crisp distinct crepuscular shafts (not soft glow + bands):
   narrower occluder gaps, higher anisotropy directionality, verified
   spot aim PER shaft. (L3 v2 shafts are soft — see its honest limit.)
2. True normal/depth-based interior shading: pec shadows, clothing
   folds and cape folds shaded by surface direction (normal/depth
   pass or estimated normals), lit side brighter / shadow side darker
   per fold — not a gradient wash.
3. Side-weighted wrap: wrap stronger on the backlit side, fading on
   the front side (needs a normal/depth pass or side-specific mask;
   a flat 2D plate cannot fake it honestly).
4. Full colour tracking on every colour in the shot (§5 fields for
   every rim/bleed/shaft/spill, not just gold).
5. Shot-to-shot consistency + time behaviour: the same L5 stack
   reproduces across a sequence, and any flicker/drift/shaft movement
   is deliberate and logged, not a render accident.
L5 is a definition and a target, not a claim. No L5 shot exists yet.

## 5. COLOR-SHIFT STUDY — why gold turned red (Mars, 17:11 + 17:14 CDT)
Mars noticed, NOT tripping — the beautiful version stays beautiful.
The point is to UNDERSTAND how overlays/environments affect colour,
and to never call a colour the wrong colour once it has been changed.

### Measured: gold rim, core ring (mask-outer, alpha > 0.9)
- Input gold rim solid: (255, 180, 80) — warm amber gold.
- Input gold bleed solid: (255, 120, 0) — already orange-red, NOT
  the same as the rim gold. Do not confuse bleed colour with rim gold.
- L3 V4 after (Blender comp, AgX + Glare): on-screen core rim
  (204, 162, 114) — desaturated amber, R down 51, B up 34, hue pulled
  toward grey/teal. At small scale / next to cyan, this reads warmer
  and redder than the input gold.
- Gold-preserved V4 (Blender comp, Standard + NO Glare): on-screen
  core rim (254, 180, 82) — essentially the input gold, within 2.
- Split test, Standard + Glare (L3 Glare settings, no AgX): on-screen
  core rim (255, 183, 89) — essentially input gold. Glare ALONE does
  not shift the V4 core rim.
- CONCLUSION for V4: the shift is the VIEW TRANSFORM, not the bloom.
  L3 left view_transform at Blender's default, which in 5.2.3 is AgX.
  AgX tone-maps bright saturated warm colours down (desaturation +
  hue pull). Standard preserves the input colour. That is the measured
  cause, not a guess.

### Measured: V5 gold side (split mask) — a SECOND, different cause
- L3 V5 gold-left ring (mask-outer-left, alpha > 0.5): (185, 156, 154)
  — pinkish-grey, the "gold turned red/pink" read Mars saw in the
  V5 after proof, strongest at the centre seam where gold + cyan
  bloom overlap (the L3 report already noted pinkish bloom there).
- Gold-preserved V5 gold-left ring: (216, 161, 159) — still pinkish.
  Standard + no Glare does NOT fully fix V5, because the split masks
  are semi-transparent by construction (mask-outer-left max alpha
  0.627, not 1.0). A semi-transparent gold ring over a cyan/teal
  god-ray background MIXES in AlphaOver: gold + cyan showing through
  = grey-pink/teal mix, before any view transform. Plus Glare fog glow
  spreads cyan light into the gold at the seam (additive pink).
- CONCLUSION for V5: two causes stack — (1) partial-alpha ring over
  a complementary-colour environment (the room/environment mix),
  (2) AgX on top of it. Fixing only the view transform fixes V4, not
  fully V5. A true gold-preserved V5 needs opaque split rings (alpha
  1.0 in the core) or a gold ring composited BEFORE the cyan bloom,
  not after it.

### General rule (STANDING, Mars 17:14 CDT)
NEVER call a colour the wrong colour once things have been overlaid
or changed. Record BOTH, every time they differ:
- colour USED (input, e.g. yellow/gold input (255, 180, 80));
- colour ON SCREEN after the mix (e.g. red/pink read (185, 156, 154));
- PLUS the cause, in plain words (e.g. "because of the mix of how it
  affects this room/environment, it makes it red" — here: AgX tone
  mapping, and/or semi-transparent gold over a cyan environment,
  and/or gold+cyan bloom overlap at the seam).
Every future shot spec must carry, for every rim/bleed/shaft/spill
colour that differs: input_color, on_screen_color, mix_cause.
If input == on-screen (within ~5 per channel), record "preserved".
This applies to ALL packs and levels, not just gold, not just L3.
