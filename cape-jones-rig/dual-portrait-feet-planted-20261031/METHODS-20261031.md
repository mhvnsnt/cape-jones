# Industry-standard scale methods — wired, 20261031

RUN = actually executed in build_feet_planted.py / check_scale_gate.py, with
a file or a gate result. MAPPING = named, not run, with the reason stated.
No vendor run is claimed without a file.

## RUN (5)
1. Fixed world anchor ratio (film / stage scale anchoring): figure height
   vs a fixed piece of furniture in the same background, transformed with
   the same cover/crop as the delivery. Anchor here: chair, back 700 to
   feet 1518 in portrait framing, height 818. Locked ratio 1.424. This is
   the check that catches the landscape regression (1.163) that a
   frame-ratio check passes. Implemented in check_scale_gate.py.
2. Floor-plane / rug position (perspective floor anchoring): feet position
   as a fraction down the floor plane, rug far edge 1421 to near edge
   1868. Old 0.284 (mid-rug, background), new 0.624 (foreground rug).
   Implemented in builder measurements and gate planted band 1650-1788.
3. Contact shadow grounding (animation / compositing grounding): soft
   dark ellipse under each foot, blurred, on a separate layer under the
   figure, never baked into base art. 2 clusters per version, visible in
   the feet crops. Implemented in build_feet_planted.py.
4. Perspective grid / floor lines (measured, not drawn over the delivery):
   rug far edge, rug near edge, wall/baseboard junction (~1420), and
   chair feet line were measured from the background-only portrait crop
   by colour profiles, and are reported in measurements-20261031.json.
   No grid lines were baked into the finals.
5. Multi-framing consistency (same character, same world, across framings):
   the same figure and the same chair anchor were measured in portrait
   AND in landscape, and the inconsistency (portrait 1.424 vs landscape
   1.163) is reported as the regression, not averaged away. Gate demo
   runs both framings.

## Gate wiring rule, going forward
Every room-scale delivery MUST pass check_scale_gate.py (exit 0) before
it is shown as a delivery: furniture ratio, frame ratio, feet planted
band, whole in frame. A frame-ratio-only pass is NOT a pass. A gate
failure is a delivery failure, not a note to fix later.
