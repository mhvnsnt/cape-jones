# LEVEL-3 SPEC (Mars, 2026-10-31 16:21 CDT, correction 16:30 CDT)

## Correction that governs this whole pass (16:30 CDT)
When Mars said "more realistic," he meant the LIGHTING and EFFECTS and GOD RAYS
to look more realistic — NOT the background itself. The background painting
stays as it is; it is NOT repainted or upgraded here. Realism applies to:
volumetric quality, falloff, bleed, shadow interaction, bloom, and light wrap
on/around him, and to the rays themselves. Any v2 background file in this folder
is a volumetric LIGHT layer behind the plate, not a new background painting.

## V4-trigger rule (standing)
When mixing reaches V4 level (layered dual rim: cyan inner + gold outer, or the
reverse, plus a mixed silhouette), the shot STARTS to get to LEVEL 3. It is not
automatically L3. A V4 mix that still only has flat rims, dark shaft bands,
no bleed and no shadow affect still reads as LEVEL 2 and must be upgraded
until it reads as L3. Mars decides whether it reads as L3; no agent claims it.

## L2 vs L3 — the test
L2 (Mars verbatim base): shadows + outer rim + colour bleed + colour key bleed,
NO god rays. In practice for these variants: flat rim rings, dark blue shaft
bands (v1: density 0.12, spot 800), no light on the character from the shafts,
ground shadow only, no bloom.
L3 (Mars verbatim base): god rays + rim + full effects. For a V4/V5 mix to
count as L3 it must have ALL of:
1. Bright volumetric god rays (not dark bands) — verified bright cyan shafts.
2. Layered dual rim (inner + outer, named order per variant).
3. Light bleed / light-effect bleed — edge-band bleed in the rim colours.
4. Light affecting shadows — ground shadow + cast shadow, AND shaft spill on
   the character (light from the rays landing on him, not just behind him).
5. More effects / more lighting effects — bloom/glare (fog glow), atmospheric
   haze, dust motes in the shafts, colour-temperature contrast (warm gold
   front ~3200K vs cool cyan back ~7000K+).
6. Motivated light — every rim/bleed/shaft names its source and direction in
   the shot spec. Unmotivated glow is not L3, it is decoration.
Missing any one of 1–5 = still L2-looking, however good the rim order is.

## 10 industry-standard god-ray upgrades wired (methods only)
1. Volumetric density tuning — 0.12 (v1, too thin) -> 0.35 (v2).
2. Anisotropy / forward scatter — 0.6, so shafts read toward camera, not flat.
3. Spot aim verified — Track To the camera, not a guessed rotation (v1's
   guessed rotation mis-aimed the cone).
4. Spot energy / multiple spots — main 8000 + two 4000 side spots (v1: 800).
5. Occluder design — thin vertical bars (not walls) so light breaks into
   distinct shafts with gaps.
6. Crepuscular / light-shaft structure — shafts + gaps + falloff, not a solid cone fan.
7. Bloom / fog glow in compositing — Glare node after the composite, threshold
   ~0.75, so only the bright shafts and rim bloom, not the whole frame.
8. Light bleed / spill — edge-band bleed + shaft spill ON the character
   (bands clipped to plate alpha), so rays affect him, not just the background.
9. Shadow interaction — ground shadow + cast shadow (offset silhouette,
   blurred, 0.45 alpha) + shaft spill, so light and shadow answer each other.
10. Atmospheric haze + dust — dust motes (emission spheres in the volume) and
    a dark world for contrast, so shafts have depth instead of reading as a
    flat backdrop.
Plus, wired through the Blender compositor (5.2 output path, verified in the
earlier fix): Image -> AlphaOver -> Glare -> GroupOutput, real render, no PIL
composite. PIL in this folder makes helper masks/solids only, never the shot.

## Dual-light correction (still in force, 15:48 CDT)
Cyan backlight / cyan god rays are for cyan rim + gold LUT/overlay combined
ONLY. Gold rim alone gets NO cyan backlight. V4 and V5 here are combined-case
shots (gold + cyan together), so cyan shafts are correct here; a gold-only
shot must not reuse this background.
