## 4. Refinements this audit proved (now standing, in the rule doc)
- COWL IS UPPER-ONLY. The buried segment in a collar crossing is the
  bicep; the lower arm stays in its normal position. Whole-chain cowl
  is BANNED (check_pose_snap.py exits 1 on cowl-whole).
- CHEST IS A WARNING, not an automatic FAIL. lower_vs_torso >1000
  flags a pose for eye-check; it FAILs only if the eye-check says the
  upper IS eaten and no snap was applied. (The dance proved the eaten
  case; stand-02/flex proved the not-eaten case.)
- Gate runs from ANGLES BEFORE rendering. A flat PNG cannot prove
  layer order after the fact, so a pose without recorded angles cannot
  pass this gate — that is a stated limit for rendered-only clips.

## 5. Pipeline step (wired, not a manual afterthought)
- check_pose_snap.py — the mandatory pre-delivery step. Command:
    python3 check_pose_snap.py --name <pose> --upperL <a> --lowerL <a> \
      --upperR <a> --lowerR <a> --head <a> \
      --applied "L:<snap>,R:<snap>" [--eye-check "<note>"] --out audit.csv
  Exit 0 = PASS (applied matches the gate, or a cowl candidate has a
  recorded eye-check). Exit 1 = FAIL (face snap missing, cowl candidate
  without eye-check, banned cowl-whole, or a face snap with no gate
  reason). Chest warnings print but do not fail alone.
  Tested in this task: jojo-03 L:none,R:face PASS; ginyu-03 + jump
  cowl-upper with eye-check PASS; ginyu-03 with no eye-check FAIL;
  jojo-02 cowl-whole FAIL; jojo-02 recorded false positive PASS
  (with chest warning).
- snap_figure.py — the snap-aware builder new poses use (normal /
  chest / cowl-upper / face passes, per side). It does NOT edit
  joint_locked_rig_v7c.py or build_poses.py: those builders are frozen
  for approved poses, so the gate sits IN FRONT of them as a mandatory
  step, documented here and in ARM-FRONT-SNAP-RULE.md. Reason stated
  plainly: editing a frozen approved-pose builder risks changing an
  approved pose; a pre-delivery gate cannot.
- Pipeline doc: stage-1 POSE gates in
  gap-audit-critique-log-20261031/PIPELINE-WIRING-20261031.md now
  include the snap gate (appended in this task).
- Industry methods: INDUSTRY-LAYERING-METHODS-20261031.md — Harmony
  Z-depth + drawing substitution, Animate layer parenting/reparenting,
  Godot Z + RemoteTransform2D, Spine keyable draw order + asset
  cutting, traditional cel stacking, Blender Grease Pencil layer tree
  (mapping only — no GP file claimed), OpenToonz/Tahoma2D SO value;
  plus not-applicable methods named with reasons.

## 6. Honest limits (not hidden)

  collar overlap at a normal shoulder attachment (3,451–4,830 px in
