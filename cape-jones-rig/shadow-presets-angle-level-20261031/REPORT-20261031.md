## 4. Honest notes, not hidden

- The room in every angle x level cell is a labelled TEST gradient room,
  not a prior render, so angle/level differences are comparable. No prior
  render is claimed as the room for these cells.
- Left vs right form gradient is subtle at contact-grid scale; the readable
  angle difference in the grid is mainly ground-shadow direction (left light
  → shadow right, right light → shadow left) plus the back row being
  darkest. Full-size cells in `angle_level/` show the form gradient clearly.
- Ground shadow px plateaus from bright to intense (e.g. overhead 72,968 →
  71,357): shadow alpha clips at 255, so raising the scale past ~1.25 adds
  brightness to the room/figure but not more counted shadow pixels. That is
  saturation, not a gate failure — figure mean still rises bright → intense.
- First build left figure brightness flat across levels (room gain only);
  caught and fixed in-run: figure-region RGB is now scaled by gain/0.85,
  alpha unchanged, so figure mean now rises monotonically darkness → intense
  in every angle row (see table above).
- Contact-sheet thumbs are proofs only; delivered cell files are full
  1100x1500, feet at 1400, never cropped. The preset-index contact's bottom
  row thumbs sit flush to the sheet edge in the thumbnail layout — the
  preset sample files themselves are full-frame, verified 1100x1500.
- No Blender Cycles / ray-traced / true volumetric shadow pass is claimed;
  those stay mapping only, as in shadows-wire100.
