# EPISODE-FIRST CHECKLIST — Space Ghost Workflow, 2026-10-31

Copy this checklist per episode. Episode ID: __________  Date: __________
Picture-lock name: ______________________  Approval: 0/1 until Mars sees it.

Tick = done with evidence (file name / timecode). A tick without evidence is
not a tick. Nothing in Phases 1–3 requires dialogue, tempo, or a QC ruling.

## Phase 0 — Shot list + picture spec
- [ ] Episode shot list written (CJ-xx IDs in episode order, not just 01→30
      if the episode re-orders them; re-ordering is an edit decision, record it)
- [ ] Each shot's spec pulled from `clean-100-20261031/shots/shot-specs-30-20261031.md`
      (pose, background, scale, level, LUT, rim, bleed, shift, audio cue ID)
- [ ] Stand-in backgrounds labelled STAND-IN per shot (never presented as final)

## Phase 1 — Picture build (per shot)
- [ ] Clean build rendered (labels off, 0 red label pixels per standing spec)
- [ ] New version-locked dated filename (never overwrote a Mars-seen file)
- [ ] Base art untouched (LUT/rim/bleed/shadow are separate layers, per spec)
- [ ] Rim follows key/LUT hue ±20°, OR dual-light exception with BOTH sources
      named and which rim belongs to which (CJ-19, CJ-30 only, per standing rule)
- [ ] Rim-question shots recorded, NOT held: CJ-05 ☐ CJ-06 ☐ CJ-26 ☐
      (current rim value kept; ruling travels to Phase 6 queue B)

## Phase 2 — Picture edit / assembly
- [ ] Shot order + per-shot hold/loop durations written in the cut sheet
- [ ] Total episode runtime written: ______ s / ______ frames @ ______ fps
- [ ] Cut is silent OR scratch-guide only; every scratch line labelled SCRATCH
- [ ] No final song laid in (tempo decision is Phase 5; dance cuts stay on the
      visual ~107 BPM grid until Mars chooses — do NOT silently stretch audio
      or visuals to fake a match)

## Phase 3 — ★ PICTURE LOCK ★ (all must be true)
- [ ] Every shot in the episode has a clean build under a version-locked name
- [ ] Cut sheet (order, holds, runtime) is complete and dated
- [ ] Backgrounds named per shot; stand-ins labelled
- [ ] Lighting/LUT/rim/bleed named per shot from the spec
- [ ] Dialogue slots exist as EMPTY timed slots (shot + in/out + speaker),
      not as lines — no line is required for this lock
- [ ] Lock name + date recorded: ______________________
- [ ] Lock communicated to the dialogue-fill step (template rows opened, lines blank)

## Phase 4 — Dialogue-fill (Mars, AFTER lock — not this checklist's builder)
- [ ] Spotting done: cue sheet rows filled (shot, TC in/out, speaker, intent)
- [ ] Mars lines recorded watching locked picture (ADR, SG-02; multiple takes kept)
- [ ] Best take selected per line; alternates kept as fallback, not deleted
- [ ] Viseme/lip pass run AFTER recording, over locked picture (SG-05)
- [ ] Any line that cannot fit its locked slot filed as a PICTURE-CHANGE NOTE
      (§6 exception path), not fixed by silently re-cutting picture

## Phase 5 — Audio pass (AFTER dialogue)
- [ ] Dialogue stem, music stem, SFX stem built separately (SG-06)
- [ ] Tempo decision applied ONLY if Mars has chosen: (a) audio → ~107 BPM /
      (b) visuals → 152 BPM / (c) accept drift — chosen option: __________
      (if blank, music stays scratch/silent and the episode does NOT claim a
      final song mix)
- [ ] If (b) chosen: knee-feet + arm-snap re-check at new speed done ☐
- [ ] Mix delivered at −14 LUFS, as a LINK, never in chat

## Phase 6 — Post-episode QC (three separate queues — do not merge them)
- [ ] Queue A — Dialogue QC: sync, intelligibility, lip drift, continuity
      (see POST-EPISODE-AUDIO-QC-20261031.md); CJ-26 + CJ-27 lines checked
- [ ] Queue B — Picture QC: rim rulings CJ-05 ☐ CJ-06 ☐ CJ-26 ☐ recorded
      (accepted as-is, or re-grade pass ordered — re-grade ≠ re-animation)
- [ ] Queue C — Final mix QC: stems balance, −14 LUFS verified, no scratch
      audio shipped as final, no silent stretch artefacts
- [ ] Any post-lock picture change re-locked under a NEW dated lock name,
      with downstream viseme/stems/QC re-run

## Phase 7 — Delivery
- [ ] Final episode under a new version-locked filename
- [ ] Audio delivered as LINK only
- [ ] Open items list attached (unfilled slots, unruled QC, unchosen tempo —
      each by shot ID), not silently dropped
- [ ] Approval recorded honestly: 0/1 until Mars sees the episode itself
