# ARCHITECTURE DECISION RECORDS (ADR) — Cape Jones, 2026-10-31

Method: ADR — one short dated record per major decision: context,
decision, consequences, status. A future rule change gets a NEW ADR
that supersedes the old one; old ADRs are never silently edited.

## ADR-01 — Face/cowl snap overrides the old head-on-top stack
Context: v7c builder drew upper arms before torso/collar, lower arms
after torso/collar but before neck/head, so a raised arm crossing the
face was eaten by head/neck/collar (JoJo 03: only a fist peeked out).
Decision: face-crossing arms go torso < head < arm (whole chain);
cowl-crossing biceps go upper-only above the collar; chest-only arms
stay torso < arm < head. Gate: face > 5,000 px, cowl candidate +
eye-check, chest = warning.
Consequences: JoJo 03 FACE-SNAP + Ginyu 01 COWL-SNAP APPROVED; Ginyu
03 + v7c-jump cowl fixes built; whole-chain cowl BANNED (JoJo 02 L
counter-proof); gate is a mandatory pre-delivery step.
Status: ACCEPTED (Mars 18:27 + 18:34 CDT).

## ADR-02 — Knee-feet is bidirectional and per-frame, never a block range
Context: v1 fix used a block range (FootIn ON frames 15-55) and flipped
an outward-knee frame (f028) inward — the exact broken read in reverse.
Decision: FootIn = True ONLY IF leg_upper L > 0 AND R < 0 on that
frame; audit table lists every frame; block range without a per-frame
table FAILS.
Consequences: 63-frame correction, 20/63 changed, 8/8 keyframes PASS,
APPROVED 100% perfect. The per-frame lesson now applies to arm snaps
too (per arm, per frame, never a block range).
Status: ACCEPTED (Mars 16:58 + 17:50-17:51 CDT).

## ADR-03 — Colour is a universe language with two dialects
Context: lighting-motivated colour and JoJo-style palette shifts were

COLOR in a shift; suit may stay white or change per beat.
Status: ACCEPTED (Mars 16:35-16:40 CDT).

## ADR-04 — Levels and preset packs are separate axes
Context: Mars could not tell some levels apart, and "level five/six"
was being used for packs.
Decision: Levels = "go to level X in the lighting" (L0-L5, never
capped at L3). Presets = "pull up lighting pack version X" (v5 =
BEFORE stack, v6 = AFTER/L3 stack). Every preset/level gets a visual
difference sheet with plain words.
Consequences: L4 APPROVED as a level; L5 defined + first shot built;
gold-preserved V5/V4 accepted as-is; colour tracking (input +
on-screen + cause) is mandatory in shot specs.
Status: ACCEPTED (Mars 17:11 + 17:14-17:15 + 18:03 CDT).

## ADR-05 — Afterglow is a motion trail, never a static rim

and read as a misplaced shadow at rest.
Decision: soft rim (cyan (0,200,255), dilate 6, blur 5, 0.60) = light
trail: present in motion, fades (lag 6, fade 0.50/0.40/0.30/0.20/

variant. That colour = his BASE afterglow colour.
Consequences: 30 shot presets saved with upgrade axes (scale,
expand, lag, fade, power_effects); hold shots generate no trail.
Status: ACCEPTED (Mars 17:36 + 17:38 + 17:49 CDT).
