# Gaussian Splatting — 8-bit upgrade (V2 / V3 / V4)

Tool name stays: **Gaussian Splatting**. This folder does NOT replace the preset.
Default 8-bit Cape Jones is still V1, in `gaussian-splatting-20261031/`
(`8-BIT-CAPE-JONES-PRESET-20261031.md`). Give V1 first whenever Mars asks for
8-bit Cape Jones; offer V2/V3/V4 only as separately labelled upgrades.

## Run it
```
python3 build_8bit_upgrade.py --preset 8bit --version V1   # reproduce V1 exactly
python3 build_8bit_upgrade.py --preset 8bit --version V2   # 8BIT-V2 DENSE
python3 build_8bit_upgrade.py --preset 8bit --version V3   # 8BIT-V3 PIXEL-GRID
python3 build_8bit_upgrade.py --preset 8bit --version V4   # 8BIT-V4 STEP-TO-CAMERA
python3 build_8bit_upgrade.py --preset 8bit --methods       # all versions + 10 methods
```
CPU only (PIL + numpy + scipy). No GPU, no torch, no CUDA, no purchase, no sign-in.

## Versions
- **V1 (preset, reproduction in this folder, original untouched):** stride 8,
  sigma 3.2, opacity 0.85, Gaussian kernel, 5,846 Gaussians, IoU 0.6472.
  Reproduction is byte-identical to the original: front md5
  `6e39ef989609038715f7a478ca6a459c`, turn GIF md5
  `a04ca47625cd7795054844cdb30c5238` — same as the originals.
- **V2 DENSE (`8BIT-V2/`):** stride 4, sigma 2.4, opacity 0.85, Gaussian kernel,
  23,391 Gaussians (4.0x V1), IoU 0.9653 (+0.3181 vs V1). Same -40..+40 out-and-back.
- **V3 PIXEL-GRID (`8BIT-V3/`):** stride 6, 6x6 box dots, opacity 1.0,
  colours snapped to a 16-colour palette taken from the plate itself,
  10,389 Gaussians, IoU 0.8815 (+0.2343 vs V1). Same -40..+40 out-and-back.
  This is the closest to a true 8-bit pixel look; V1/V2 remain soft-dot splats.
- **V4 STEP-TO-CAMERA (`8BIT-V4/`):** stride 8, sigma 3.2, opacity 0.85,
  5,846 Gaussians, IoU 0.6472 at front. Motion EXPLICITLY differs: turn halved
  to -20..+20, scale 0.85 -> 1.25 -> 0.85, lower-body Gaussians shift +/-18px
  alternately. This is a stepping PROXY, NOT a walk cycle, no walk keys, feet
  are not planted (peak frame bbox y 126-1484, height 1,359px, 15px margin).

## Mars's V1 readings, preserved (2026-10-31 20:19 CDT)
1. V1 looks like it partially rotates three-quarters, then rotates back the
   other direction three-quarters, like in 3D space. That is the -40 to +40
   and back out-and-back motion — like the THREE-QUARTER PSEUDO TURN, NOT a
   full turn, NOT a true back view. V2 and V3 preserve that exact motion.
2. V1 almost looks like walking, taking steps towards the camera. That is a
   READING of the depth-bulge rotation shifting legs/feet alternately, NOT a
   true walk cycle — no walk keys were used in V1, so never call V1 a walk
   cycle. Only V4 makes stepping explicit, as a labelled proxy.

## Honest limits (all versions)
Depth is a SYNTHETIC bulge proxy (distance transform; sampled max V1 81.9px,
V2 84.5px, V3 83.2px — the sampled max differs because the stride grid differs).
NOT a true multi-view reconstruction, NOT a scanned back, NOT a measured depth
map. A true back still needs Mars's FLA back pieces. Front splats are proofs,
not clean plates. Vendor CUDA implementations (gsplat, splatfacto, Nerfstudio
viewer, Blender Gaussian-shader render) are MAPPINGS, not runs — no torch/CUDA
on this VM, and no paid GPU run was made.
