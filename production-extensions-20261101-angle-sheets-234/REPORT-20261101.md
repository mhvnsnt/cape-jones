## What "generated" means here (honest labelling)
- GENERATED-DERIVED: scale / squash / trapezoid warp / rotation / compositing
  of EXISTING slices only. No new character art was drawn, and no AI image
  generation was used. A derived piece is a usable swap, not a native view.
- REISSUE / EXISTS-PRIOR: byte-identical copy of an existing slice, renamed
  to the spec name. Pixels unchanged.
- SPEC-ONLY: no PNG. Writing a spec is not generating a sheet, and this
  report never claims otherwise.
- DERIVED-ASSEMBLY (parts-layout): existing slices laid out in figure /
  near-to-far order at the spec's scales, with gaps left intentional so each
  part stays readable. It is NOT a posed figure and NOT a native angle sheet:
  the source slices are disconnected, and joining them into one body would
  require inventing shoulder/hip/cape connecting art, which was refused.
