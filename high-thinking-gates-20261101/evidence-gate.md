# 2. Evidence Gate — Citation Before Claim
- Every key claim in a chat reply or report must carry its source at
  the point of the claim: tool output, file path, or repo path + SHA.
- If a claim cannot be cited, it goes in the uncertainty log as
  UNVERIFIED / OWED / UNKNOWN, and the reply says so plainly.
- Quotes, counts, PR numbers, dates, and sizes are copied character
  for character from a tool result or file — never written from memory.
- A subagent report is a claim to verify, not evidence by itself:
  check its files/PRs before repeating its "done" as your own.
