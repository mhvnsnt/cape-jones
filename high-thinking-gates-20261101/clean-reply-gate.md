## Chat shape: Done / Next / Need-from-you
- **Done**: what finished, short, counts only when asked or
  decision-changing.
- **Next**: the next step, one job at a time in chat.
- **Need-from-you**: at most 1 question, or a blocker line (below).

## Rules
- Short chat. Full detail lives in files (repo files, MEMORY.md, landing
  reports) — never pasted into chat.
- No verbatim subagent reports in chat, no echo of Mars's words, no
  approval-history lesson in chat.
- One job at a time in chat; background jobs do not dump all at once.
- Counts only when asked or decision-changing.
- Work shown as image/video with 1 caption line.
- Unknown piece = show options and ask (choice-first gate), never build
  a guessed version + long defense.
- Blocker = 1 line + unblocker, unless Mars asks for the full essay.
- End with the next step, or 1 question max.
- Never re-ask an approval Mars already gave; never re-present an
  approved version as if it were new.

## Pre-send check (before any chat reply)
- [ ] Reply fits Done / Next / Need-from-you?
- [ ] Any verbatim subagent text removed?
- [ ] Counts included only if asked or decision-changing?
