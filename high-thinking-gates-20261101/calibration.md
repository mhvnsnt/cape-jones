# 4. Calibration — Atomic Claims, Confidence, "Why Not 100%"
Adapted from CLAIM-CAL: break a reply into atomic, independently
checkable claims; interrogate each with a support-seeking probe AND a
contradiction-seeking probe; label each Supported / Contradicted /
Unknown. Then:
- Give a confidence % for the conclusion, not vague certainty.
- For anything below 95%, state "why not 100%": the gaps, in plain terms.
- 100% is reserved for mathematical/logical certainty or a repo check
  (size + SHA match on main after merge).
- Explanation quality is not evidence quality: a thorough-sounding
  paragraph with no tool output behind it is speculation, labelled so.
