# Cape Jones Cowl Colors (Option List)

**Owner rule (2026-10-29):** the cowl color is an OPTION LIST, same as the
lighting looks. A scene picks the color it wants; new colors get added as
the next number. Nothing gets voted off.

**How a swap works today:** in the current 3D model his color lives in the
body texture, so using another color from this list is a recolor pass on
that texture — the list is the record of which colors exist and what
they're called.

---

## CANON DEFAULT — #3E1473

The deep violet he wears. Locked with the show palette on 2026-10-17
(suit #FFFFFF, skin #E5B28C, cape #000000). Every scene uses this unless
the scene names another color from this list.

## COWL COLOR #2 — #B35DF3

A bright orchid violet. This is the color that was sampled into the
MaterialX proof file (`tools/wired/fullstack/cape_jones_materials.mtlx`
carries it as linear RGB 0.45, 0.11, 0.90 — the same color). Renamed from
"the estimate" to plain **Cowl Color #2** by the owner on 2026-10-29.
